# Chakaram-Board-game
Chakaram is a faithful, fully playable 3D web implementation of Chowka Bara (also known as Katte Mane, Daayam, and Ashtapada) — an ancient South Indian cross-and-circle strategy game that predates chess and Ludo by centuries, yet remains largely forgotten today.  Built with Three.js, it runs entirely in the browser with no installation required.
